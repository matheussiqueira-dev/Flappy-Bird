# Assets

Esta pasta é reservada para recursos visuais e sonoros da engine Python original.

Estrutura sugerida:

```text
assets/
├── images/
│   ├── bird.png
│   ├── pipe.png
│   ├── background.png
│   └── ground.png
├── sounds/
│   ├── jump.wav
│   ├── score.wav
│   └── hit.wav
└── demo.gif
```

No estado atual, a engine Python desenha os elementos proceduralmente via Pygame.
Os assets web da PWA ficam em `public/`.
